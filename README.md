# Growth Assistant para iPhone

Este projeto é uma PWA: depois de publicado em HTTPS, abra o link no Safari e use:
Compartilhar -> Adicionar à Tela de Início.

Funciona sem computador depois de instalado.

## Funções
- Instagram e YouTube
- pesquisa por nicho
- fila de perfis/canais
- botão "Abrir perfil/canal"
- confirmação manual de follow/sub
- marcação de follow-back
- taxa de retorno
- histórico no próprio iPhone
- exportação CSV
- funcionamento offline depois do primeiro acesso

## Publicação
Recomendado: GitHub Pages.
Arquivos devem ficar na raiz do repositório.

Depois:
Settings -> Pages -> Deploy from a branch -> main / root.

A URL gerada pode ser adicionada à Tela de Início no iPhone.

## Observação
O app não executa follow/sub automático em massa. Cada ação é aberta na plataforma e confirmada pelo utilizador.
